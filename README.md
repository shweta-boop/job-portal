# Job Portal Application

## 📌 Description

A full-stack Job Portal application where job seekers can search and apply for jobs, and recruiters can post and manage job listings.

## 🚀 Features

* User Authentication (Login/Signup)
* Job Posting (for recruiters)
* Job Search & Apply (for candidates)
* Real-time updates (if implemented)
* Secure APIs using JWT
* Role-based access (Admin / Recruiter / User)

## 🛠️ Tech Stack

* Backend: Node.js, Express.js
* Database: MongoDB
* Frontend: Angular / React (mention yours)
* Other: JWT Authentication, REST APIs

## 📂 Project Structure

* `/backend` – API and server logic
* `/frontend` – UI (if added)

## ⚙️ Installation & Setup

```bash
git clone https://github.com/shweta-boop/job-portal.git
cd job-portal
npm install
npm start
```

## 🔐 Environment Variables

Create a `.env` file and add:

```
PORT=5000
MONGO_URI=your_mongodb_url
JWT_SECRET=your_secret_key
```
